# Instabilità del reattore

Alcuni pack abilitano un livello extra di **instabilità / pressione** sopra il normale funzionamento del reattore. Quando è attivo per il tuo salvataggio, l’HUD e le letture del **Reactor Controller** mostrano avvisi o limiti legati alla stabilità—segui quei messaggi e regola combustibile, refrigerante o layout come indicato dalla UI.

Le definizioni di heat sink e refrigerante includono moltiplicatori che influenzano quel livello solo mentre l’instabilità è attiva nella config **common**.

Se il controller non menziona mai l’instabilità, puoi ignorare questo argomento.
