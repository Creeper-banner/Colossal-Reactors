# 反应堆红石接口

<BlockImage id="redstone_port" scale="4" />

**反应堆红石接口**连接红石信号与反应堆状态（如输出比较器信号或对输入的信号作出反应，取决于设定）。

## 特性

- **右键点击**打开配置界面，即可选择反应堆状态与红石信号的映射关系，鼠标悬停查看各个模式的介绍。

- 注意朝向，以使得自动化设备可**从外侧**读取或操控端口。
