# 反应堆稳定性

某些整合包可能会在通常的反应堆操作之外，开启一项额外的**不稳定性 / 压力**属性。当次属性启用时，**反应堆控制器**的面板上会显示与稳定性相关的警告或是限制，此时需要根据界面中的提示对燃料、冷却剂或反应堆布局进行调整。

散热方块和冷却剂定义包含影响稳定性的系数，但只在稳定性相关特性在配置文件中开启时有效。

若反应堆从未提示稳定性相关内容，则可忽略本节。
