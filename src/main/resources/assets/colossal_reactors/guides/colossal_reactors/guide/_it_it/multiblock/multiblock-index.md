# Reattore

Un reattore è un guscio cavo costruito con **Reactor Casing** e **Reactor Glass** (facce trasparenti). All’interno si collocano **Reactor Rod** di combustibile, **heat sink** opzionali, **fluido refrigerante** opzionale, **porte** sul casing e esattamente un **Reactor Controller** che gestisce il funzionamento e le letture a schermo.

**Nuovo qui?** Leggi prima [Per iniziare](getting_started.md) — **Esempio completo**, poi **Setup 1** (solo RF) o **Setup 2** (refrigerante → turbina).
