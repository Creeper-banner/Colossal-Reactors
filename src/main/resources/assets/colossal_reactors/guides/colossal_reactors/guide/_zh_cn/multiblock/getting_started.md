# 起步指南 —— 第一台反应堆

建造一个封闭的反应堆外壳，并选择下方两种配置之一。旋转渲染图来查看各个面。

## 外壳布局

- **顶面和底面**：**反应堆外壳**（封闭框架）；
- **竖直角块**：在四处边缘放置**反应堆外壳**（y=1…5）；
- **南、西、北侧墙壁**：每个面放置**5×5 反应堆玻璃**（5 行 × 5 列，放置在四角的柱体之间）；
- **控制器侧面**（示例中为北面）：**反应堆控制器**作为**单个方块**向外伸出，此面其他没有接口的位置放置**反应堆玻璃**；**接口替换此面的反应堆玻璃**，与其他面风格一致，不使用裸框架；
- **接口**：在**控制器的同一面**，可位于面上的**任意位置**（示例中有意将其放置在远离控制器的位置）。

[反应堆建造器](reactor_builder.md)可放置反应堆外壳、反应堆玻璃（若物品栏中有）、燃料棒和散热方块，**不放置**控制器和接口。

## 散热方块和冷却剂

两者为**不同系统**：

| | **散热方块**（被动）| **冷却剂**（主动）|
|---|---|---|
| **是什么** | 填充在外壳内，与燃料棒相邻的方块或**静止流体** | 控制器缓存 / 资源接口中的**工作流体** |
| **如何放置** | 建造器 / 人工在反应堆内放置（包括“流体散热方块”） | 控制器冷却剂槽，或配置二中的**输入/提取**端口 |
| **运行时是否消耗** | **否** | **是**（可能产生蒸汽或耗尽） |
| **RF 模式是否需要** | 可选（改变 RF 产量和燃料消耗） | 配置一中**不需要** —— 冷却剂储罐**留空**即可 |

放在反应堆内部的流体散热方块与向冷却液回路输入的水**不同**。参见：[反应堆结构](reactor_structure.md).

## 配置一：简单电力堆（仅 RF）

在**只想通过反应堆发电**时使用 —— 此配置不需要蒸汽处理和汽轮机。

1. 建造外壳和内部（燃料棒 + 燃料棒顶部的燃料棒控制器）；
2. 按照示例中的方式放置**控制器和能量接口**（控制器位于**外侧**，能量接口替换**玻璃**）；
3. 控制器的冷却剂储罐**留空**，不需要流体冷却剂；
4. 添加燃料（可通过控制器 GUI 或 漏斗 / 管道），打开控制器 → **有效** → **开启**；
5. 将**能量接口外侧**连接到能量接收器，并检查 **产能（RF/t）** 是否大于 0.

**可选自动化**（示例中有展示）：在**同一面**放置两个**资源接口**，并在 GUI 中进行配置（**输入** / **提取**、过滤、介质切换），各个按钮的作用参见[资源接口 GUI 说明](resource_port.md)。切换端口模式后需要**重启**。

| 接口（示例位置） | 模式 | 过滤 |
|------|------|--------|
| 控制器面左下方 | **输入** | **仅燃料** |
| 控制器面右下方 | **提取** | **全部** 或 仅固体 |
| 控制器下方一格 | 能量接口 | （输出 RF） |

也可以手动操作，不放置资源端口，直接在控制器中手动装填燃料。

## 配置二：冷却剂（产生蒸汽）

在需要用水（或其他冷却剂）产生**蒸汽**并送入[汽轮机](../turbine/getting_started.md)而不直接产生 RF 时使用（也可同时直接发电）。

1. 建造同样的外壳并在其中一面放置**控制器和能量接口**（若反应堆仍然产生 RF 则仍然需要能量接口）；
2. 在反应堆控制器中设定**冷却流体**（通常为**水/蒸汽**）；
3. 在**同一面**放置两个**资源接口**替换反应堆玻璃：
   - **输入** — **仅冷却剂**（或全部），将冷却剂**送入**反应堆；
   - **提取** — **仅冷却剂**，从反应堆中**抽出**蒸汽或热冷却剂；
4. 使用配置一的**燃料输入**和**废料提取**部分，或手动处理燃料和废料；
5. 将反应堆**提取**端口中的蒸汽输入[汽轮机资源接口](../turbine/getting_started.md)（输入），即可从汽轮机能量接口输出能量。

随着转换率变化，反应堆**发电功率**可能下降而**蒸汽产生**提高，这是正常现象。此外需要保证汽轮机尺寸合适和蒸汽流量足够，参见[汽轮机入门指南](../turbine/getting_started.md)。

切换冷却剂、过滤器或接口模式后需要**重启**反应堆。

## 检查清单

1. 外壳是否封闭：上下两面和角落柱体使用外壳、三个面上使用 **5x5 玻璃**，控制器面使用**玻璃 + 端口**，控制器单独放在外侧；
2. ** [反应堆控制器](reactor_controller.md) **单独放置在侧面外部；
3. **能量接口**（和可选的资源接口）位于**控制器同一面**；
4. **配置一**和**配置二**任选其一；
5. 可选**红石端口**。

## 反应堆建造器（可选）

1. 建造器仅放置**框架和内部方块**；
2. **停止建造**并以示例中的方式在**其中一面**放置控制器（在外侧）和端口；
3. 通过控制器验证结构。

## 反应堆无法启动

| 现象 | 常见原因 |
|---------|----------------|
| 结构**无效** | 需要修复外壳、燃料棒以及燃料棒控制器（阅读状态信息） |
| **开启**但不产能 | 缺少能量端口或能量接收器。或是进入了冷却剂模式但没有供给 / 提取路径 |
| 有红石端口并**保持关闭** | 需要调整红石端口模式 |
| 核废料无法输出 | 缺少**提取**资源端口或过滤设置不正确 |
| 不产生蒸汽 | 未设置冷却剂，输入耗尽，或缺少冷却剂**提取**端口 |
