# 反应堆

模组中的反应堆，外壳部分由**反应堆外壳**和**反应堆玻璃**（透明面）构成，内部可放置**燃料棒**、可选的**散热方块**和**冷却剂**，端口放置在外壳上。反应堆还需要恰好一个**反应堆控制器**，负责控制反应和显示读数。

**第一次游玩？**建议先阅读[入门指南](getting_started.md)，其中包含完整的**反应堆示例**和两种配置（仅 RF / 使用汽轮机）。
