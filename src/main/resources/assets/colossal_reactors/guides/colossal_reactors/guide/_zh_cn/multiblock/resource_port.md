# 反应堆资源接口

<BlockImage id="resource_port" scale="4" />

**反应堆资源接口**可放置在外壳部位，用于反应堆内外的物品和流体交互。

## 常见布局

### 手动 / 仅能量（不放置）

燃料和核废料可恶意直接通过[反应堆控制器](reactor_controller.md)的 GUI 交互。此时反应堆仍然需要一个[能量接口](power_ports.md)。

### 自动装入燃料和排出废料（两个接口，放置在控制器面）

两个接口需要放在**控制器的同一面**。[入门指南](getting_started.md)的示例中两个接口分散放置，将鼠标悬停在示意图的方块中可查看提示。

| 接口（示例） | 模式 | 过滤器 | 动作 |
|------------|------|--------|-------|
| 左下 | **输入** | **燃料** | 向燃料棒**输入**燃料 |
| 右下 | **提取** | **核废料** | **输出核废料** |

接下来，在此面添加一个**能量接口**，并将各个资源接口连接至管道。

### 冷却剂流体循环（**额外接口**，可选配置）

若使用**主动冷却剂**（如[入门指南](getting_started.md)的配置二）：

- 一个接口设置为**输入**和过滤**冷却剂**，用于输入冷却剂（输入：*仅冷却剂流体*）；
- 一个接口设置为**提取**和过滤**冷却剂**，用于抽出**蒸汽或热冷却剂**，之后可参见[汽轮机入门指南](../turbine/getting_started.md)（*输出：仅热冷却剂*）；
- **提取核废料**应该设置在另外的接口，以避免输出接口意外弹出不恰当的流体。

## GUI、按钮和说明

打开 GUI 并将鼠标**悬停**在按钮上可以看到文字说明。

### 模式（顶部按钮）

| 标签 | 说明 |
|-------|---------|
| **输入** | 接受固体燃料和冷却剂流体 |
| **提取** | 输出核废料和热冷却剂 |
| **弹出** | 弹出反应堆内容物 |

### 过滤（仅反应堆，用于燃料或冷却剂循环）

悬停查看当前过滤，与**模式**相关。

| 模式 | 过滤标签 | 说明 |
|------|--------------|---------|
| **输入** | 全部 / 燃料 / 冷却剂 | *输入燃料和冷却剂 / 仅燃料 / 仅冷却剂* |
| **提取** | 全部 / 核废料 / 冷却剂 | *输出固体核废料和热冷却剂 / 仅核废料 / 仅冷却剂* |
| **弹出** | 全部 / 仅燃料 / 仅冷却剂 | *弹出燃料物品和冷却剂 / 仅燃料 / 仅冷却剂* |

### 介质切换

| 按钮 | 说明 |
|--------|---------|
| **固体** | 接受 / 阻挡一般物品 |
| **液体** | 接受 / 阻挡流体 |
| **气体** | 接受 / 阻挡通用机械气体 |

### 储罐、清空按钮

| 控制 | 说明 |
|---------|---------|
| **流体储罐** | 流体名称 / 存储量 / 容量 |
| **气体储罐**（通用机械） | 气体名称 / 存储量 / 容量 |
| 流体储罐下方**D**按钮 | 清空（销毁）内部流体 |
| 气体储罐下方**D**按钮 | 清空（销毁）内部气体 |

- **物品槽位**需要手动交互或者通过接口**外侧**用管道交互。

调整接口模式或过滤之后需要**重启**[控制器](reactor_controller.md)。

## 自动扩大容量

反应堆**重新验证**时，各个资源端口会调整流体 / 气体容量：

- 目标容量 ≈ **接口对应流体 / 气体的预计流量 × 10**，最低**16,000 mB**；
- 对于大型反应堆**无固定容量上限**；
- 需求升高时容量**自动扩展**，仅在缩小后仍然满足需求时缩小。
